# GCN · Goodmorningpet CareNet (자동 업데이트판)

굿모닝펫동물병원 원내용 케어노트 뷰어입니다.

- 화면 코드(HTML/CSS/JS)만 이 저장소에 있습니다.
- 환자·보호자 정보와 진료 데이터는 저장소가 아니라 구글 시트(`GCN_실시간_데이터`)에서 읽어옵니다.
- 시트를 고치면 앱에서 `🔄 새로고침`만 누르면 반영됩니다.

## ➕ 시술 체크 (플러스·마이너스) — 2026-11-28 신설
진료 예약 줄마다 항목별로 `+ 진행·추가` / `− 진행 안 함`을 원터치로 찍고, 안 누른 칸은 `미체크`로 남깁니다. 같은 버튼을 다시 누르면 해제됩니다. 누가·몇 시에 눌렀는지 함께 남고, 날짜 머리의 `⛔ 미시행 모아보기`에서 그 날 − 만 따로 모아 복사할 수 있습니다. 항목 목록은 `⚙️ 시술 항목 관리`에서 코드 수정 없이 추가·삭제합니다(기본 8개: 리브렐라·사이토포인트·넵트라·렙트라·불소도포·스케일링·레이저·FMT).

- 저장 위치: 이 기기의 localStorage (`gcn_proc_v1`, 항목 `gcn_proc_items_v1`, 이름 `gcn_proc_who_v1`).
- **기기끼리(접수 PC ↔ 진료실 폰) 값을 맞추려면**: Apps Script 미용 체크 웹앱에 `시술체크` 탭용 `proc` 액션을 추가해 새 버전으로 배포한 뒤, `index.html`의 `var PROC_SYNC=false;`를 `true`로 바꿉니다. 붙여 넣을 코드: `work_1128_proc/Code_시술체크_추가.gs`.
